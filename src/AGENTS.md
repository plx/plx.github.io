# Site source

For visual changes, read [the design system](../docs/DESIGN_SYSTEM.md).
Semantic color tokens already switch with dark mode; only the `accent` token
supports Tailwind opacity modifiers.

Type checks intentionally use both `astro check` (classic TypeScript) and the
pinned native `tsgo` preview. Compatibility reasons and upstream watch items
live in [the migration plan](../planning/major-migration-plan.md).
